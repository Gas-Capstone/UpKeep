## Changes to Habits
The habits page is now integrated with our backend. Before this, habits and their corresponding data would be stored locally in memory, causing any habits to be deleted once the user closed the app. Now, they're tied to the user's account. The user interface hasn't changed.
- Habits are now stored in the database
    - This includes habit title, time of day, frequency, and who created them
- Habit completions are now stored in the database
    - This includes which habit was completed, who completed it, and when it was completed
- Interactions such as creating a habit, deleting a habit, and completing a habit will update the database accordingly, allowing data to persist between app launches
