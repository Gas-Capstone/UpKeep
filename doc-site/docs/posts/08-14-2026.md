# Sprint 3

#### August 14, 2026

###### written by: tbraud03, pdinger0, KarkaVon, ZeRoCodesBZ

## Overview

August 14 marks the end of Sprint 3. In this sprint, we added more user settings, the ability to create and favorite meals and workouts, and added backend integration to the Habits page.

## New User Settings

The settings page includes being able to change new aspects of the app
- This includes Date of Birth, Display Name, and User Profile Picture
When loading up the app for the first time, a Getting to know you popup will appear
- The popup asks you for your DOB, Display Name, and Profile Picture.
- You can fill out whatever you want, or none at all. If you exit the popup it will not appear again, and the user will have to go to settings to change them after
When loading up the app on your birthday, if you have a DOB stored in your profile
- A popup alert appears wishing you a happy birthday
- Added a Function to take in all needed Biometrics in settings
- - Also appears in the "create profile" popup

## Changes to Workouts

- Users can create their own workout plans consisting of individual workouts
- When a user starts a workout session, they can view the individual exercises
    -individual exercises can have the remaining number of sets decremented; when all sets are complete, the exercise gets marked as complete
    -when all exercises are complete, the workout sessions completes and gets logged

## Changes to Meals/Recipes

The meals page now has a "favorite meals" function, as well as the ability to create custom recipes.
- A new button to add ingredients to your fridge is placed at the top of the screen
  - The modal allows you to input recipe name, prep time, and ingredients
- Custom recipes are displayed at the bottom of the recipe list (for now)
- Each recipe card now has a "favorite" button
  - Favoriting a recipe anchors it to the top of the recipe list for easy access
  - This also works with custom recipes
- Fridge items now show the unit associated with each ingredient and allows the user to set the quantity of each ingredient.
- Added "grocery list" feature
  - Users can view 3 grocery list types: "quick add", "meal plan", and "combined" lists
  - Users can add custom items not in the ingredient catalog (i.e. paper towels)
  - When items within the ingredient catalog are checked off, that item gets added to the fridge
- Users can create a weekly mealplan
    - Users can pick out meals to make between the current week and following week
    - Each day has set slots for meals (breakfast, lunch, dinner, snack); additions to an already filled slot will overwrite that slot
    - The app tracks what ingredients a mealplan requires. Any missing ingredients can be added to a mealplan grocery list through a button

## Changes to Habits
The habits page is now integrated with our backend. Before this, habits and their corresponding data would be stored locally in memory, causing any habits to be deleted once the user closed the app. Now, they're tied to the user's account. The user interface hasn't changed.

- Habits are now stored in the database
  - This includes habit title, time of day, frequency, and who created them
- Habit completions are now stored in the database
  - This includes which habit was completed, who completed it, and when it was completed
- Interactions such as creating a habit, deleting a habit, and completing a habit will update the database accordingly, allowing data to persist between app launches

## Changes to Home

Added a new Calorie Goal Estimate system and related Widget
- if needed data isn't set for profile, gives a prompt to fill in info
- Created a new Context file to pull all of the related calorie info from

Removed the redundant cards linking to other pages

Added Consistency Markers that track your completed habits/workouts and what foods you tend to stick to
- Compares against Missed Habits/Workouts and Possible Missing Nutrients to compute a "Wellness Score".

## What's Next?

In the future, we plan to improve the UI all around. We want to make the UX more intuitive and enjoyable. We also aim to refine some features and add new features such as the following:
- Add ability for user to mark recipes as completed, and that recipes required ingredients get pulled from the fridge
- User receives daily (in the morning) message on current status such as planned meals and habits for that day
- Turning data into actionable insights that can help the user measure their progress
- Add alternating motivational quotes to the home screen
