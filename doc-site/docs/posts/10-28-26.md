# As a user, I want the workout timer features to be expanded and have the same style as the rest of the UI
*Written by tbraud03*
- The workout timer page has been entirely revamped to provide a more streamlined experience
- The timer now sits at the bottom of the page, and it now counts up instead of down
- Exercise info has been expanded
  - You are now able to adjust sets, reps, and weight during the workout timer
  - There is also an info section for each exercise, allowing you to view muscle group, equipment, and instructions on how to perform each exercise
- PRs on exercises are saved and displayed to the user during workout sessions

- Workout logging has been expanded
  - On the history modal, you are now able to view more detailed info about each workout session
  - Shows individual exercises, as well as number of sets and reps

- The exercise catalog has been greatly expanded
  - 800+ new additions, each with info about muscle group, equipment, and instructions
  - These exercises were pulled from the exercises.json file found at https://github.com/yuhonas/free-exercise-db
  - While I tried to match our existing exercises with those found in the exercise database, not all of them were able to be linked/matched, meaning some older exercises won't have as detailed information. There's also a chance of duplicate exercises

- The workout creation and edit flows have been updated to account for the new exercises
  - A new exercise picker has been added, presenting a list of options, with the ability to search by name and filter by equipment and muscle group
    - The picker also allows you to view exercise information/instructions
  - The exercise listing on the create/edit modal has also been updated, allowing easier changes of sets and reps
  - The edit workout page has been replaced with a modal, with the same layout as the creation modal
  - Input validation when the user selects "save", enforcing required fields such as name and expected time

- The "Planned duration" modal upon pressing "start workout" has been removed
  - This was a vestige of when the timer counted down, and only served to disrupt the flow of using the app for workouts
  - The "planned duration" is now pulled from the value set when the user created the workout plan, and can't be changed
    - The value can still be changed by editing the plan, however

# As a user, cooking a recipe uses up what's in my fridge
*Written by: Brayd-n*

- When you finish cooking and hit "Done", a popup now shows up so you can update your fridge
- It lists each ingredient the recipe used next to how much you have, like "Recipe uses 1 cup · You have 2 cups"
- You can change any of the amounts if you used a different amount than the recipe says, or clear it if you didn't use that ingredient at all
  - "All" uses up all of that ingredient
  - "Swap" is for when you used something else instead, like oat milk instead of regular milk
- Hitting "Update fridge" takes everything out of your fridge at once, and anything you run out of gets removed
- If you don't want to change your fridge you can just hit "Skip"
- If the recipe and your fridge use different units (like cups vs oz) you can just type in how much you used
- I also fixed a bug where the fridge page wouldn't update after something changed it, so it would still show the old amounts


# As a user, the profile page is clear and easy to use
*Written by: Brayd-n*

- You can now tap anywhere on the primary goal card instead of just the arrow, and it takes you right to the primary goal in settings
- I moved the wellness details (height, weight, age, sex) up into the main profile card with your name and picture, and added an "Edit" button for them
- There were a few buttons that all went to the same settings page, so I cleaned that up
  - I got rid of the settings cog at the top and the extra settings button under Account
  - "Edit profile", the primary goal card, and the wellness "Edit" button each take you to their own part of settings now
